Oil lamp

The lamp runs on its own ESP32 with its own LEDs, so it is not controlled from here.

In the show it lights first; once it is fully lit, this board runs the TRAVERSE opener across INNOV IOT and then settles into BREATHE.

The lamp board can trigger that automatically by sending show start over serial to this board — the firmware already accepts it. Its own controls will live on this tab.
